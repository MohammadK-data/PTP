# Public Information Request - Fort Bend Central Appraisal District (FBCAD) (draft, ready to send)

**Why.** Fort Bend Central Appraisal District publishes the files listed in `source_register.csv`. The items below are not published (checked 2026-10-12 and 2026-11-16) and are needed for commercial protests.

**Legal basis.** Texas Government Code Chapter 552 (Public Information Act). Sale price information from private sources may be withheld under §552.149; owner-rendered income under Tax Code §22.27. Evidence for a protested account must be given to the owner/agent under Tax Code §41.461.

**Where to send.** FBCAD Public Information: https://www.fbcad.org/ (Open Records).

## Draft request text

Subject: Public Information Request - commercial real property records

To the Public Information Officer, Fort Bend Central Appraisal District:

Under the Texas Public Information Act (Government Code Chapter 552), I request copies of the following existing records in electronic form (CSV, TXT, XLSX or ZIP) by e-mail or download link. Please send an itemized cost estimate first if charges will exceed $40.

1. Commercial income model parameters 2023-2026 (rents, vacancy, expenses, cap rates) by property type.
2. Segment code list with descriptions for all commercial segment codes.
3. Sale prices used in commercial ratio studies 2023-2026 (may be withheld under Gov. Code §552.149).
4. Agent of record by account for tax years 2025 and 2026: account number (QuickRefID), agent ID and agent name, from the appointment-of-agent (Form 50-162) records. The public Orion exports list agent names only, with no link to accounts.
5. Protest records for tax years 2025 and 2026: account number, protest filed date, filed by (owner or agent ID), notice (pre-protest) value, resolution type (informal settlement, ARB order, withdrawn, no-show), final value, and hearing/order date.

If any item is withheld, please identify the exception claimed and release the remaining items.

Thank you,

[Name, company, e-mail, phone]
