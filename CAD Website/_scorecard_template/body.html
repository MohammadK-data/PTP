    Method & open questions

    How the numbers were built

    One row per propertyEvery property in the protax JSON (493,110) appears once. A property with a 2026 appeal of type P counts as protested. When there are several 2026 appeals, one decides the result: ours first, then a finalized appeal, then the latest one.
    ValuesNotice = the first 2026 appeal's initial market value. Final = the latest finalized appeal's final market value. Multi-owner properties are put on the owners' basis (rule from travis_values.py). Missing values come from the Oct 6 certified roll, which matches the JSON final on 99.7% of closed appeals.
    Win and reductionA win is any cut from notice to final (or the threshold picked above). Reduction % = total cut ÷ total notice. Avg % / property averages each property's own cut. Fee estimate = 1% of our market cut, before collections and caps.
    PathsInformal = ORDT, EF_AS and I (TCAD marks these as informal decisions). Formal ARB = ORD2 to ORD13 and other formal orders. No-show = FTA. Withdrawn = W, EF_WD. Dismissed = D, LD. Open = not finalized on Oct 6.

    Open questions

    • Which agent IDs are ours? This page counts 1863738, 1898343 and 1898284, all listed by TCAD as Property Tax Protest. 1897915 ("Property Tax Protest AKA Watchtower Protest") is treated as another firm.
    • Agent of record vs. filer. We are on file for about 2,400 more properties where someone else (often Ownwell) filed the 2026 appeal, or nobody did. Those count for the filer, not for us.
    • 2026 only. No prior-year values are used, so there is no year-over-year section.
    • No assessed values. The page measures market value; capped (taxable) value and tax savings are not shown.
